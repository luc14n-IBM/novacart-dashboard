Test infrastructure

  • Backend: FastAPI TestClient (wraps httpx) — in-process, no live server. Wired to data/novacart_gold.db (real SQLite data, 30 000 orders). Two fixtures: client (Dev mode) and spcs_client (SPCS mode, CLIENT_VALIDATION patched on the live module).
  • Frontend API client: Global fetch stubbed with vi.stubGlobal — no network calls. Stub is restored after every test.
  • Frontend component: getHealth mocked at module level via vi.mock. Rendered into a jsdom environment with React Testing Library.
